## Technische Details

Dieses Projekt stellt das PDF-Buch als HTML-Website bereit. Die Inhalte wurden in AsciiDoc konvertiert.

**HTML generieren:**
```bash
asciidoctor index.adoc
```

Die generierte `index.html` enthält die vollständige Dokumentation mit allen Bildern.
